One example, held constant.

Maria works for fictional Atlas Demo Transport, MC 1234567. A fixture supplies eligible authority and a matching future dry-van load, DEMO01, from Texas to Georgia. It opens at 1900, counters Maria's 3000 with 2025, and reserves when she accepts.

All example data is synthetic. Whole native amount units and UTC parsing are implementation assumptions; upstream currency and timezone are unconfirmed. Rep sending is conditional on send mode being enabled.

PLAIN-LANGUAGE REFERENCE

Terms you can explain to someone else

API / HTTP
An application programming interface: named requests and responses between programs. HTTP is the request/response protocol used by the service and platform APIs.
TCP / ASCII
TCP carries a stream of bytes, without message boundaries. ASCII is the text encoding used by the legacy TMS protocol.
SMTP
The email-delivery protocol the service uses to send the demo code.
Hash / HMAC
A hash is a one-way fingerprint. HMAC adds a secret key, allowing code checks and stable pricing draws without exposing that key.
JSONB
A database type storing structured JSON values, such as a call record and its event list.
UTC
A global time standard. The adapter assumes upstream TMS dates are UTC; the upstream timezone is not confirmed.
Carrier
The trucking business that moves the freight. Its dispatcher may call on its behalf.
Brokerage
The intermediary arranging a carrier to move a customer's shipment. Our voice agent handles its initial inbound sales work.
MC number
A US motor-carrier docket identifier used for the authority lookup. Knowing a number is not proof of identity.
FMCSA
The US Federal Motor Carrier Safety Administration. Its API supplies the authority evidence used by the service.
OTP / code
A one-time six-digit code. This demo sends it to a configured shared inbox before load access.
Load / lane / equipment
A shipment; its origin-to-destination route; and the truck/trailer type it needs.
TMS
Transportation Management System. The external legacy system holding load records and accepting booking requests.
Twin
HappyRobot's saved data store. This service uses call and booking rows, each with a version and event history.
Tool
A constrained action the voice model requests. The workflow turns it into an authenticated service request.
run_id
The workflow's call identifier, injected outside the model's tool arguments and used as the call-row key.
Public view / allowlist
An explicit selection of fields allowed to cross a boundary. New internal fields are excluded by default.
Ceiling / cap / opening
The upstream maximum, our lower working limit, and the first offer. These are different numbers.
Terms / Step
Temporary typed objects: pricing terms for a load, and the result of one negotiation decision.
CAS / row version
Compare-and-set: save only if the row is still the version read. A changed version means someone else acted.
Claim
An ID-bearing saved intention used to recover the gap between a call-row agreement and a load-row reservation.
Reservation
Our local hold after agreement. Nothing has yet been sent to the TMS.
ACK_PENDING
A valid PENDING receipt with a booking reference. Acknowledged is not finally confirmed.
UNKNOWN
The external send might have landed. Keep blocked, preserve evidence and never automatically resend.
Reconcile
A rep-triggered read-only TMS check. Current status-only reads cannot prove carrier/rate ownership or finalize a pending booking.
Cohort
A real or synthetic label fixed when a call is created. Real-call KPIs exclude synthetic records.
Structured event
A saved service decision and its details. It is not an audio recording or a verbatim transcript.
Northstar
The principal local KPI: recorded reservations divided by calls that ever passed the code, for the real cohort.
Mocked transfer
The agent announces a senior-rep handoff. No actual telephone transfer occurs in the web-call demo.
Read retry / write retry
Reads may repeat within a bounded budget. A booking write never automatically repeats because a lost reply does not prove the write failed.
