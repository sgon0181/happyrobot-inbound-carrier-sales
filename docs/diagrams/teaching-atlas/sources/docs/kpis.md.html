1# KPI definitions23Scope: only call rows whose stored cohort is real. Synthetic calls stay visible separately. A deploy check historically stamped real is explicitly excluded.45| Display | API field | Definition and limits |6|---|---|---|7| Calls recorded | calls | Number of real Twin call rows. Not an answer rate or guarantee every platform run was captured |8| Code passed | code_passed | Real calls that ever recorded a successful code check. A later MC change does not erase this milestone.
