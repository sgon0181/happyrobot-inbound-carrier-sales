The one thing the live call needed most was thrown away.58- **Uncertain outcomes:** avoid false denial as well as false confirmation. "Not booked" can be as wrong as "booked".59- **Closing a call:** a close flag, the words spoken, the session ending and a scenario grade are four separate facts.60- **Tool Call Result:** field visibility is separate from HTTP success. Successful replies stay hidden from the model until safe fields are explicitly exposed.61- **Tool authentication:** a passing tool-selection grade does not prove an integration works, so confirm the call reached the service.62- **Twin access:** Viewer cannot write, and creating tables through the API failed with it. The lab's table was created in the UI.63- **Time limits:** a per-read budget is not a request deadline. Search made several reads with no overall limit.64- **Transcripts:** the voice and text formats differ, and redaction must cover failed code attempts as well as the successful one.65- **Hosting:** Fly's trial logs stopped the machine after 5 minutes. The call was inside a fresh run, so this did not cause its failure.66- **Email sends:** do not silently retry an uncertain send.67- **Scenario tests:** a full-workflow scenario will not run without an enabled Northstar grader. A text session tests conversation flow, not audio.6869## How the lab differed from the design7071- **Storage:** eight logical maps in one JSON row, which proves the locking primitive, not the schema.72- **TMS reads:** sequential detail reads, with no overall search deadline.73- **Email:** the deprecated action-test route, with one instance at a time.74- **Rep actions:** the app wrote directly to Twin, a shortcut the product must not copy.
